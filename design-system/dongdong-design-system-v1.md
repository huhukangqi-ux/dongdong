# 动动 Design System v1.0

视觉组件总览：[dongdong-ui-kit-v1.png](./dongdong-ui-kit-v1.png)

## 1. 品牌气质

- 关键词：简洁、可爱、轻松、荒诞、鼓励行动。
- 页面以白色画布和留白分层，不依赖卡片边框区分模块。
- 黑色负责信息层级和主操作；淡蓝色只用于交互强调；杏桃色只用于外星人；黄色只用于庆祝或提醒的小面积点缀。
- 奖励可以隆重，失败表达要轻松。避免竞技、压迫和羞辱感。

## 2. 色彩 Token

| Token | 色值 | 用途 |
| --- | --- | --- |
| Ink | `#111111` | 主文字、图标、主按钮 |
| Paper | `#FFFFFF` | 页面背景 |
| Sky 300 | `#A9D5F5` | 选中态、次按钮、进度、导航高亮 |
| Sky 100 | `#DDEFFC` | 角色衬底、轻提示背景 |
| Apricot | `#F2B27D` | 外星人主体 |
| Mist | `#F4F5F7` | 禁用背景、弱分区 |
| Gray | `#9CA3AF` | 辅助文字、未完成状态 |
| Star | `#FFC928` | 撒花、星星、未读提示 |

使用约束：

- 单个页面彩色面积建议不超过 20%。
- 淡蓝色是唯一交互强调色，不再引入紫色、绿色或高饱和红色。
- 不使用渐变、玻璃拟态、立体阴影和霓虹效果。

## 3. 字体层级

- 大标题：40px，粗体或窄体黑体，行高 48px。
- 页面标题：28px，粗体，行高 36px。
- 模块标题：22px，粗体，行高 30px。
- 正文：16px，常规字重，行高 24px。
- 按钮文字：17px，中等字重。
- 辅助文字：13px，常规字重，行高 18px。
- 数字和计时器使用等宽数字。
- 一个页面最多使用三个字号层级，不使用大段全粗体。

## 4. 布局与尺寸

- 设计基准：390×844 手机画布。
- 页面左右边距：24px。
- 8pt 间距系统：8 / 16 / 24 / 32 / 48px。
- 同组组件间距：8px。
- 模块内部间距：16px。
- 大模块之间：32px。
- 最小点击区域：44×44px。
- 主按钮高度：56px，圆角 16px。
- 输入框高度：48px，圆角 14px。
- 底部导航内容高度：64px，另加安全区。
- 内容通过留白和对齐分层；非必要不增加容器背景、描边或分割线。

## 5. 按钮规范

### 主按钮

- 背景 `Ink`，文字 `Paper`。
- 用于当前页面唯一的主要动作，例如“开始救援”“完成选择”。
- 同一视区最多一个主按钮。

### 次按钮

- 背景 `Sky 300`，文字 `Ink`。
- 用于“快速一分钟”“选择替代动作”等次级任务。

### 文字按钮

- 黑色文字，可使用短下划线或右箭头。
- 用于“调整计划”“稍后再说”“查看全部”。

### 禁用状态

- 背景 `Mist`，文字 `Gray`。
- 不用降低到难以辨认的透明度。

## 6. 选择与输入组件

- 选择标签：高度 36px；未选为 `Mist`，选中为 `Sky 300`。
- 单选和复选：24px；选中使用淡蓝填充及白色勾。
- 开关：48×28px；开启使用 `Sky 300`。
- 输入框：白色或 `Mist` 底，不使用粗描边；聚焦时使用 2px 淡蓝提示。
- 时长选择：3 / 5 / 10 / 15 分钟，单选。
- 计步器：减号、数值、加号三个点击区均不小于 44px。
- 错误提示紧邻控件，使用文字说明，不仅依赖颜色。

## 7. 计划组件

### 周计划

- 一行展示周一至周日。
- 已完成：黑色圆形勾选。
- 今日：淡蓝色块或短下划线。
- 未来：中灰空心圆。
- 休息日：仅显示日期，不强化状态。

### 能量点

- 默认使用 5 个圆点。
- 未开始：全部 `Mist`。
- 进行中：已完成部分使用 `Sky 300`。
- 完成：全部使用 `Sky 300`，可出现一次轻微弹跳。

### 救援任务

- 文案与外星人横向排列，文案占约 55%，角色占约 45%。
- 不使用任务卡边框。
- 信息顺序：任务标签 → 外星人名字 → 计划名称 → 能量点 → 主操作。

## 8. 内容组件

### 动作列表行

- 最小高度 72px。
- 左侧动作图标，中间名称和时长，右侧收藏。
- 默认不使用行框；必要时通过 16px 间距区分。
- 左滑露出“更换”“删除”，右滑执行收藏。

### 好友状态行

- 头像、昵称、今日状态、社交操作横向排列。
- 完成使用淡蓝勾；未开始使用中灰状态。
- “锤锤”每天对同一好友最多一次。

### 挑战预览

- 展示挑战名、参与人数、完成条件和自选惩罚。
- “加入挑战”为主动作；夸夸、锤锤和评论为弱操作。
- 惩罚公开展示必须单独授权。

### 个人数据

- 优先展示累计天数、累计分钟、每周完成率。
- 使用数字＋短标签，不使用复杂仪表盘。

## 9. 导航

- 顶部导航：返回／页面标题／一个右侧操作。
- 一级 Tab：好友／广场，选中使用淡蓝底。
- 底部导航：今日／社区／我的。
- 当前项使用淡蓝图标或短下划线；其他项使用黑色线性图标。
- 沉浸页如跟练、完成反馈不显示底部导航。

## 10. 反馈与弹层

- Toast：短句，约 2 秒自动消失，例如“已加入收藏”。
- 半弹层：用于调整计划、替换动作、选择惩罚；顶部有拖拽条和清晰标题。
- 确认弹窗：只用于退出运动、公开惩罚等不可忽略的决定。
- 成功状态：淡蓝背景、杏桃色外星人、少量黄色星星。
- 部分完成：说明已经传送的部位和继续所需时间，不使用失败文案。
- 身体不适：立即暂停动作并提供降低难度、更换动作或退出。

## 11. 外星人插画规范

- 采用无外轮廓的扁平矢量风格。
- 主体使用杏桃色，眼白为白色，瞳孔为深灰或黑色。
- 单个角色尽量由 3～5 个大色块构成。
- 身体、眼柄、手臂和短腿浑然一体，不强调连接环、插口、关节或弹簧纹。
- 依靠眼神、嘴型、倾斜角度和整体姿态表达情绪。
- 禁止写实质感、密集线条、复杂阴影和高光。
- 首页角色宽度约 120～150px；列表角色约 40～56px；完成页角色可放大至 220～280px。

角色基础状态：

- 默认：微笑站立。
- 运动中：身体倾斜或手臂伸展。
- 成功：双手举起，搭配少量黄色星星。
- 部分完成：疲惫但不痛苦，表情仍然轻松。

### 外星人十色系列

| 编号 | 名称 | 主体色 | 建议气质 |
| --- | --- | --- | --- |
| 01 | 杏桃 | `#F2B27D` | 默认、亲切、活跃 |
| 02 | 奶油黄 | `#E5C86F` | 乐观、轻快 |
| 03 | 苔藓绿 | `#9DBA78` | 自然、稳重 |
| 04 | 雾薄荷 | `#8FBFA9` | 清爽、放松 |
| 05 | 雾蓝灰 | `#8FAAC1` | 安静、理性 |
| 06 | 薰衣草 | `#B4A6C9` | 温柔、梦幻 |
| 07 | 豆沙粉 | `#D3A0AA` | 可爱、细腻 |
| 08 | 陶土橘 | `#D18F6C` | 热情、勇敢 |
| 09 | 燕麦米 | `#C8B79E` | 松弛、慵懒 |
| 10 | 深海青 | `#6F9E9A` | 神秘、冷静 |

使用规则：

- 十种颜色只表达角色身份和性格，不承担成功、失败、危险等功能语义。
- 同一只外星人的颜色在首页、跟练、社区、图鉴和完成动画中保持一致。
- 眼白统一使用 `#FFFFFF`，瞳孔和嘴统一使用 `#111111`。
- 角色周围的界面选中态仍统一使用淡蓝 `#A9D5F5`，不随角色颜色变化。
- 当角色主体为雾蓝灰或深海青时，应使用白色或极浅蓝背景，避免与淡蓝交互控件重叠。
- 默认角色使用 01 杏桃；其他颜色可用于不同角色、星球系列或图鉴收藏，不建议仅作为稀有度换色。

## 12. 动效规则

- 普通点击反馈：150～200ms。
- 页面与弹层切换：250～300ms。
- 成功庆祝：1.2～2 秒，只播放一次。
- 能量点按进度逐个点亮。
- 角色动作使用整体弹性位移，不依赖大量局部线条。
- 支持减少动态效果；关闭动效后仍能通过状态文字理解结果。

## 13. 页面复用映射

| 页面 | 复用组件 |
| --- | --- |
| 进入页 | 大标题、主按钮、次按钮、默认角色状态 |
| 信息选择页 | 步骤进度、标签、单选、复选、时长选择、计步器、提醒输入 |
| 计划首页 | 救援任务、能量点、周计划、动作列表、底部导航 |
| 运动跟练页 | 顶部进度、计时器、动作反馈按钮、控制栏、暂停半弹层 |
| 完成反馈页 | 成功／部分完成状态、数据摘要、感受选择、分享按钮 |
| 社区 | Tab、好友状态行、挑战预览、互动按钮、庆祝／惩罚弹窗 |
| 个人页 | 数据摘要、徽章、角色图鉴、设置列表、底部导航 |

## 14. 给原型生成 AI 的固定约束

> 所有页面必须沿用“动动 Design System v1.0”：390×844 手机画布，24px 页面边距，8pt 间距系统；白色无边框页面，黑色主信息与主按钮，淡蓝色作为唯一交互强调色，杏桃色只用于外星人，黄色仅用于庆祝微元素；不使用渐变、投影、玻璃拟态、厚描边和彩色卡片。外星人使用无外轮廓扁平矢量风格，身体结构简洁连续，不强调连接点。所有主要点击区域不小于 44px。
